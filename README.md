# 🚀 Landing Page - BrandUp

Este repositório contém o código de uma **Landing Page moderna e responsiva**, desenvolvida com foco em **design clean**, **responsividade** e **boas práticas de front-end**.

## 🖥️ Tecnologias Utilizadas

- **HTML5** → Estrutura semântica da página.
- **CSS3** → Estilização com boas práticas de design.
- **SCSS (Sass)** → Pré-processador CSS para melhor organização e manutenção do código.
- **JavaScript** → Interatividade e comportamento dinâmico.

## 🎨 Conceitos Aplicados

- **Design responsivo** → Adaptável a diferentes tamanhos de tela (desktop, tablet e mobile).
- **UI/UX** → Layout focado em experiência do usuário e identidade visual clara.
- **Boas práticas de CSS/SCSS** → Estrutura modular e escalável.

## 📂 Estrutura do Projeto

```
landing-page-brandup-main/
│── index.html        # Estrutura da página
│── css/              # Arquivos CSS compilados
│── scss/             # Estilos em SCSS
│── assets/           # Imagens e ícones
│── package.json      # Dependências do projeto
```

## ⚙️ Como Executar o Projeto

1. Clone este repositório:
   ```bash
   git clone https://github.com/seu-usuario/landing-page-brandup.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd landing-page-brandup-main
   ```
3. Instale as dependências (se necessário):
   ```bash
   npm install
   ```
4. Compile o SCSS para CSS (se desejar editar os estilos):
   ```bash
   npm run build
   ```
5. Abra o arquivo `index.html` no navegador.
